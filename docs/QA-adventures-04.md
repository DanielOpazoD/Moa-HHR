# adventures-04 · Moa aventuras

Preparación, revisión visual y publicación por el asistente principal, sin subdelegación. Escenas: B13, B15, B16, B17, B23, B24. 72 poses editables. Fuentes, prompts, JSON, PNG individuales, atlas y previews sobre tres fondos preservados.

Pruebas unitarias y metadatos locales mediante npm test. El entorno local bloquea el lanzamiento de Chromium por sockets: no se afirma una prueba local de navegador. Se exige CI de GitHub con reconstrucción editable exacta, diez pruebas Chromium y galería offline antes del merge. Sin cambios a motor, tests ni workflow. Safari/Firefox y dispositivos físicos no comprobados. Secuencias discretas raster de duración finita, no interpolación continua.

Estas animaciones no se conectan a eventos del sistema. Cualquier integración futura debe disparar guardado/sincronización solo tras confirmación real de éxito, respetar movimiento reducido, permitir detener/repetir y acompañar el estado con texto accesible independiente. No representar una operación pendiente como completada. No se modifica ni despliega HHR.

Revisión de continuidad: B13 y B17 usan fuentes de dos columnas para evitar cortes entre personajes. B16 conserva la manta amarilla antes de ofrecerla. B17 conserva una única burbuja tras el estornudo. B23 reduce la duplicación del frasco y conecta la sonda al equipo; la pantalla muestra exclusivamente un corazón ilustrado, sin interpretación médica. B24 utiliza un brazo de simulación y no muestra valores de presión. Duraciones variables con pausa final más larga, 5,85 s por escena. Las imágenes son viñetas de fantasía y cuidado, no material para enseñar procedimientos.
