# companion-02 · Moa compañero

Preparación, revisión visual y publicación por el asistente principal, sin subdelegación. Escenas: A06, A07, A08, A09, A10. 60 poses editables. Fuentes, prompts, JSON, PNG individuales, atlas y previews sobre tres fondos preservados.

Pruebas unitarias y metadatos locales mediante npm test. El entorno local bloquea el lanzamiento de Chromium por sockets: no se afirma una prueba local de navegador. Se exige CI de GitHub con reconstrucción editable exacta, diez pruebas Chromium y galería offline antes del merge. Sin cambios a motor, tests ni workflow. Safari/Firefox y dispositivos físicos no comprobados. Secuencias discretas raster de duración finita, no interpolación continua.

Estas animaciones no se conectan a eventos del sistema. Cualquier integración futura debe disparar guardado/sincronización solo tras confirmación real de éxito, respetar movimiento reducido, permitir detener/repetir y acompañar el estado con texto accesible independiente. No representar una operación pendiente como completada. No se modifica ni despliega HHR.

Revisión de continuidad: A06 v2 corrige la mano que sostiene la lupa en el cuadro 8; A07 v2 conserva el lápiz sobre el escritorio cuando no se usa; A10 v2 sostiene la antena con ambas manos. A07 representa una copia y comprobación visual entre dos carpetas, no sincronización real ni garantía de persistencia. Las láminas son composiciones de frames, no capturas de navegador.
