# companion-03 · Moa compañero

Preparación, revisión visual y publicación por el asistente principal, sin subdelegación. Escenas: A11, A12, A13, A14, A15. 60 poses editables. Fuentes, prompts, JSON, PNG individuales, atlas y previews sobre tres fondos preservados.

Pruebas unitarias y metadatos locales mediante npm test. El entorno local bloquea el lanzamiento de Chromium por sockets: no se afirma una prueba local de navegador. Se exige CI de GitHub con reconstrucción editable exacta, diez pruebas Chromium y galería offline antes del merge. Sin cambios a motor, tests ni workflow. Safari/Firefox y dispositivos físicos no comprobados. Secuencias discretas raster de duración finita, no interpolación continua.

Estas animaciones no se conectan a eventos del sistema. Cualquier integración futura debe disparar guardado/sincronización solo tras confirmación real de éxito, respetar movimiento reducido, permitir detener/repetir y acompañar el estado con texto accesible independiente. No representar una operación pendiente como completada. No se modifica ni despliega HHR.

Revisión de continuidad: A11 v2 conserva la mesa hasta el final. A12 v2 mantiene los cuatro personajes, incluido el amigo de hoja verde en el cuadro 4. A13 v2 elimina el cubo duplicado del cuadro 9. A14 v5 conserva la hoja hasta archivarla, mantiene el lápiz al dejarlo sobre la mesa y separa las celdas para evitar cortes del dibujo. Se preservan las cinco fuentes de A14. A15 muestra aceptar ayuda y ofrecerla después, con tres personajes identificables. Las láminas son composiciones de frames, no capturas de navegador.

Cierre de la serie: 15 escenas, 160 poses (40 simples, 60 intermedias, 60 complejas). Biblioteca acumulada: 153 escenas, con 18 originales y 135 nuevas; 1.636 PNG editables. No se certifica ausencia absoluta de variación raster entre poses: la revisión comprueba legibilidad narrativa, continuidad principal, identidad y límites de recorte.
